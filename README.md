# УК РФ — % оправдательных приговоров и разбивка исходов

Приложение (Streamlit) показывает по статьям УК РФ долю оправдательных приговоров, разбивку исходов
дел и размеры наказаний. **Все цифры считаются прямо из исходных файлов Судебного департамента
при Верховном Суде РФ**, лежащих в репозитории без изменений. Их же можно скачать на странице приложения.

Запуск:
```
pip install -r requirements.txt
streamlit run app.py
```

## Файлы

| Файл | Что это |
|---|---|
| `data/raw/form_10_3_<год>.xls` | Форма 10.3 «Отчёт о видах наказания по наиболее тяжкому преступлению», 2016–2025, без изменений |
| `data/raw/form_10_3_1_<год>.xls` | Форма 10.3.1 «Отчёт о сроках лишения свободы и размерах штрафов», 2016–2025, без изменений |
| `forms.py` | **Вся обработка данных** (≈180 строк, из них половина — таблицы и комментарии): поиск колонок, суммирование по статьям, расчёт долей |
| `article_names.json` | Какие статьи показываем и их названия (рус./англ.) |
| `app.py`, `style.css` | Интерфейс |

Файлы в `data/raw/` только переименованы для единообразия (в оригинале, например, `K7-svod_vse_sudy-2025.xls`
для формы 10.3 и `K7.1-svod_vse_sudy-2025.xls` для 10.3.1); содержимое — как получено.

## Что делает `forms.py`

1. **Колонки.** В разные годы колонки стоят по-разному, поэтому нужные находятся по тексту шапки
   (`OUTCOME_COLUMNS` для формы 10.3, `sentencing_key` для 10.3.1), а не по номеру колонки.
2. **Статьи.** Номер статьи — первое число в подписи строки; все части и редакции статьи
   («264 ч. 1», «264 ч. 2», «… в старой редакции») суммируются в одну статью.
   Строки без номера («Воинские преступления», итог «Всего по составам») в расчёт не входят.
3. **Показатели.** Формулы — в функции `outcomes`.
4. **Не опубликовано.** Если статья была в отчёте прошлого года, а в отчёте последнего года её строка пуста,
   год помечается как `unpublished_years` и в приложении показывается «н/д», а не нули.

## Какое наказание получили осуждённые (форма 10.3)

Все осуждённые по статье раскладываются без остатка: реальное лишение свободы на срок + пожизненное +
условное лишение свободы + условное к иным мерам + штраф + иные основные наказания (работы, ограничение
свободы, арест, лишение права, воинские) + освобождённые от наказания (зачёт срока, амнистия, иные основания).
Колонки — `PUNISHMENT_COLUMNS` в `forms.py`. Остаток `sent_unallocated` показывается явно, если он не равен нулю:
в самих таблицах он есть в 2016 г. (по ст. 291.2 ±1, в сумме 0), 2017 г. (ст. 264, 1 чел.) и 2025 г. (13 чел.).

Доля условного осуждения = условно осуждённые к лишению свободы ÷ (все приговорённые к лишению свободы:
реально, включая пожизненное, + условно). Доля от всех осуждённых — в таблице видов наказания.

Диаграмма сроков (форма 10.3.1) показывает только лишение свободы на срок, поэтому её сумма меньше «осуждено».
В форме 10.3.1 «лишение свободы: всего» совпадает с графой «лишение свободы» формы 10.3 (без пожизненного);
единственное расхождение между итогом и суммой интервалов — 1 человек по ст. 105 в 2021 г.

Сумма по статьям меньше строки «Всего по составам УК РФ» на строку «Воинские преступления» (4 409 чел. в 2023 г.,
9 206 в 2024 г.): в отчёте она не разбита по статьям, поэтому в приложение не входит.

## Методика

"Всего рассмотрено" = осуждено + оправдано + прекращено (реабилитирующие основания) +
прекращено (нереабилитирующие основания) + принудительные меры медицинского характера
к невменяемым. Все проценты в разбивке считаются от этой суммы (в сумме дают 100%).

- Реабилитирующие основания — отсутствие события/состава преступления, непричастность.
- Нереабилитирующие основания — амнистия + примирение с потерпевшим + деятельное
  раскаяние + судебный штраф (ст. 25.1 УПК РФ) + иные основания. Служебное поле
  "прекращено на основании примечаний к статьям УК" НЕ прибавляется отдельно — это
  подмножество поля "иные основания".

Также считается `pct_of_verdicts` — % оправдательных от числа приговоров (осуждено + оправдано).

## Как добавить новый год

1. Положите файлы формы 10.3 и 10.3.1 в `data/raw/` как `form_10_3_<год>.xls` и `form_10_3_1_<год>.xls`.
2. Добавьте год в `YEARS` в `forms.py`.
3. Если в отчёте появились новые статьи — добавьте их в `article_names.json`.

## Оговорки по данным 2025 года

1. В отчёте 2025 г. пусты строки по ст. 275–284.3 и 330.1 УК РФ и строка «Воинские преступления»
   (в файле они сохранены без названий и значений). Это пропуск данных, а не отсутствие дел;
   в приложении они показаны как «н/д».
2. Общее число осуждённых в 2025 г. (437 840) на 14,6% ниже, чем в 2024 г. (512 845). Это данные
   источника; из-за пропусков данных их нельзя трактовать как реальное сокращение.
3. С 2025 г. в форме 10.3 не заполняется графа «прекращено по амнистии» (в 2024 г. — 11 человек).
4. В 2025 г. остались только действующие редакции статей; утратившие силу статьи даны одной строкой
   без частей. На уровне статьи целиком (как в приложении) это не влияет.
5. Считаются люди (лица), а не дела: форма 10.3 учитывает каждого по наиболее тяжкому (основному) составу
   преступления, без учёта сложения, поэтому показатели по статье — это не все приговоры, где статья упоминалась.
6. Строки отчёта 2021–2022 гг. с несколькими статьями сразу («222 ч. 5; 222 ч. 6; …») отнесены к
   первой статье строки.
